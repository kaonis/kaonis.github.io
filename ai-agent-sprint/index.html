    Questions §7

    The things people ask first

    Which model, and can we use something other than Claude?

    Default is Claude through the Anthropic API, because the tool-use and long-context behaviour is the most predictable for this kind of work. If you need an EU-hosted or open-weights model for policy reasons, say so on the call. The evals tell us if it holds up.

    Where does our data go?

    To your model provider account under your own data processing terms, and to infrastructure you control. I work on a sample during the sprint and delete it at handover. A short data processing agreement is included in the contract.

    What if we have no API for the system the agent needs to touch?

    Most SaaS tools have one. For the ones that do not, we fall back to email, CSV exports, or a shared inbox the agent reads. That is usually fine for a first version and we discuss it in week one.

    Can you do this for a mobile app or an internal tool instead?

    Yes. The same fixed-scope format applies to React Native work and infrastructure setups. Email me what you have and I will tell you whether it is a sprint or a smaller job.

    How many sprints can you run at once?

    Two. I keep capacity deliberately small so each sprint gets daily attention. Start dates are first come, first served, and a signed deposit holds your slot.
